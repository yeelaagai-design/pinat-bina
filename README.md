# מאגר פינת בינה

מרחב הקלטות הסדנאות של שבוע הבינה המלאכותית המחוזי, משרד החינוך מחוז הדרום ותקשוב דרום.

האתר הוא קובץ `index.html` אחד, בלי שרת ובלי התקנות. התיקייה `slides` מכילה את תמונות השקפים שמוצגות בגלריות.

## פרסום ב-GitHub Pages
Settings > Pages > Build and deployment > Source: Deploy from a branch > Branch: `main`, תיקייה `/ (root)` > Save.
